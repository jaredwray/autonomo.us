# Loading motion review captures

Captured by Chromium against the implemented React views, using delayed synthetic API responses in `core/ux/browser/loading.spec.ts`. No credentials or personal data were supplied. Source run: https://github.com/jaredwray/autonomo.us/actions/runs/43977980120 (UI commit `96aa16bd8d4de6b64eb66b5f955dcabac67b4adf`).

The loading captures show the actual Models view at 1280px/dark and 320px/light; the proposal captures show the completed empty state at 1280px and 320px in dark mode.

These static images show spacing, colors, wrapping and one frame. They cannot show animation timing, smoothness, live announcements or reduced-motion behavior. Browser tests verify changing transforms, disabled animations under reduced motion, polite status semantics, error/completion cleanup, responsive bounds and retained focus. No screen-reader speech testing was performed.
